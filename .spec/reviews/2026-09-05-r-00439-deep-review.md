## Findings

### P0-1：写入 ABI 丢失契约要求的 transaction ID，A-2 无法实现跨重试幂等

- 契约明确要求“一批写入是若干条目加一个事务 ID”，且重复提交同一事务 ID 必须返回同一回执、不得再次生效：
  `engine/wire/voxel-world-v1.json:1977-1980`。
- ABI 的 `block_write_prepare` 只有 world、entry 指针、entry count 和 out token，条目结构也只有
  SectionKey / cellOffset / BlockId / expectedSectionRevision：`engine/abi/native-abi.json:128-135`、
  `engine/abi/native-abi.json:370-383`。
- C 与 Rust 生成签名同样没有 caller-supplied transaction ID：
  `engine/native/modules/sdk-native/include/lumio_engine.h:158`、
  `engine/native/modules/sdk-native/src/abi_generated.rs:174`。

失败场景：prepare token 丢失、进程边界重试或调用方重新 prepare 同一事务时，provider 没有稳定的调用方事务身份，
无法判定是重试并返回原回执，只能重复应用或发明未授权的进程内规则。此项违反冻结契约并把关键决定留给 A-2。

### P0-2：完整 ABI 没有任何 physics query slot，明确要求的 overlap buffer 协议不可调用

- 冻结契约规定 raycast / overlap / sweep 的具体 C 签名与结构布局必须落在
  `native-abi.json`；overlap 必须接收调用方缓冲和容量，并返回实际总数与 truncated：
  `engine/wire/voxel-world-v1.json:325-342`、`engine/wire/voxel-world-v1.json:819-822`。
- R-00439 详细要求也逐字要求“重叠结果”使用 caller-supplied buffer / capacity / actual / truncated。
- 新增 root slot 和生成器的 required slot 清单只有 block read/write/revision/pin 十项：
  `engine/abi/native-abi.json:113-160`、`eng/generate-abi.mjs:32-43`；所有被审 ABI/生成文件中
  `overlap|physics|raycast|sweep` 为 0 命中。

失败场景：下游只能另写一个 overlap FFI 或根本无法跨 ABI 调用；现有
`query_buffer_overflow` 等错误常量没有可返回它的 ABI 操作。该缺口直接未交付卡面要求。

### P1-1：生成 C Header 没有唯一入口函数声明

- 仓库公开接口要求 Header 生成 `lumio_engine_get_api_v1(requested_version, out_api)`：
  `README.md:76-78`、`.spec/knowledge/features/architecture.md:55-62`。
- 新 Header 只定义状态、类型、函数指针和 root struct，随后在
  `engine/native/modules/sdk-native/include/lumio_engine.h:205` 结束；该文件对
  `lumio_engine_get_api_v1|requested_version|out_api` 均为 0 命中。
- Rust / C# 生成物至少带 entry symbol 常量，C Header 连 ABI version、definition hash 常量也没有。

失败场景：C/C++ 消费方包含唯一生成 Header 后仍不能声明式调用唯一导出，只能手写第二份 prototype，
违反“Header / Binding 均从 native-abi.json 生成”的单一真值纪律。

### P1-2：生成器的“51 个错误映射”门只数数量，不比名称、顺序或唯一性

- `eng/generate-abi.mjs:54-67` 只比较 wire hash、contractId、三个 count，并只要求 ABI error array
  长度为 51；没有比较 `voxel.errorCodes` 与 `wireContract.errorCodes`。
- `eng/generate-abi.test.mjs:50-67` 只检查三个 direct case，未断言完整 51 项相等、唯一且逐语言输出一致。

当前补丁里的 51 项经独立脚本比对确实与 wire **逐项同序相等**，C / Rust / C# 也分别生成 51 个唯一数值
`1000..1050`；但把任意其余名称改成自造错误或交换顺序，现有 generator + tests 仍会绿。
这是本卡最关键验收项缺少反例门禁，不符合公共 ABI 改动的测试要求。

### P2-1：C 的 presence 不是声明的固定宽度无符号类型

`native-abi.json` 把 presence 定为 `u32`；Rust 用 `#[repr(u32)]`，C# 用 `enum : uint`，但 C Header 用
`typedef enum lumio_voxel_presence_t`：`engine/native/modules/sdk-native/include/lumio_engine.h:13`、
`engine/native/modules/sdk-native/src/abi_generated.rs:64-65`、
`engine/managed/Lumio.Engine.NativeLoader/AbiConstants.g.cs:19`。C enum 的底层类型不保证是 `uint32_t`；
本机 MSVC x64 当前布局为 4 字节，因此本次 offset 未漂移，但生成物没有做到跨语言固定宽度类型一致。

## Verdict

**RETURN**。两个 P0 使冻结公共语义无法由下游 A-2 实现；两个 P1 使生成 Header 与错误映射门禁不完整。

## 验收覆盖

| 验收项 | 结论 | 证据 |
|---|---|---|
| 1. 含批量读 / 写入提交 / SectionRevision slot | **失败** | 十个声明 slot 存在，但写入缺 transaction ID，且卡面明确要求的 overlap ABI 缺失（P0-1/P0-2）。 |
| 2. generator 跑通、源与生成物同批、无手改 | **通过** | 六文件生成前后 SHA-256 逐文件相等；generator exit 0。 |
| 3. 缺块四态显式、不用零填充 | **通过** | presence 四态；cell/batch result 均有 `has_block_id`，Pending/Unavailable 文档要求为 0；revision 独立存在。 |
| 4. C# BlockId=`uint`，世界 y 无符号 | **通过** | C# `BlockId` 为 `uint`，world/section y 为 `byte`；C/Rust 分别为 `uint32_t/u32` 与 `uint8_t/u8`。 |
| 5. 51 个契约错误稳定对应、不塌缩 | **当前数据通过，门禁失败** | ABI 与 wire 51 项逐项同序相等，生成值唯一为 1000..1050；generator 不校验名称/顺序（P1-2）。 |
| 6. ping / CLR / timer 不破坏，verify-wire 7 份全绿 | **静态通过，运行证明缺口** | 基线 22 个 root fields 是新表的逐字节相等前缀；abiVersion 仍为 1，voxel 从 offset 200 追加至 size 280；verify-wire 全绿。dev-run / cargo 因隔离 worktree 缺外仓依赖未跑通。 |

补充逐项结果：

- 当前 contract hash / count：**通过**，hash `e474...02869`，51 / 56 / 110。
- BlockId 32-bit unsigned、world y unsigned、cellOffset y/z/x=256/16/1、read 262144、write 65536：**通过**。
- pin declare/release/status 三槽、caller-supplied pin budget、ready 状态：**通过**。
- batch read 两组 caller buffer + capacity + actual + truncated：**通过**；overlap 同类要求：**失败**。
- x64 C root layout：**通过**，size 280，旧末槽 timer_drain=192，新槽 200..272。
- C / Rust / C# 类型布局：C 与 Rust 实测关键结构一致；C# 生成物编译通过，但仓内没有新增 voxel layout test；
  presence 的 C 底层类型仍有 P2-1。
- A-2 usability：**失败**，transaction ID 和 physics query 插口缺失；不能要求 A-2 自行补公共语义。

## Known Gaps

- 隔离 review worktree 的父目录没有 `LumioNativeCore`、`LumioVoxelEngine`、`LumioGameRuntime`、`LumioClient`。
  `dev-build.ps1` 默认解析前两者且 `dev-run.ps1` 不转发 override；Client 路径又被硬编码为 sibling。
  因此不能在不改脚本/不造外部 junction 的前提下完成 cargo 与 Host live proof。
- 已在运行前审读 `dev-run.ps1`：指定的 `C:\Work\LumioGames\LumioServer` 只被读取 manifest、按需 cargo build、
  启动已有 binary，运行日志/audit/ready 均写 Temp；Server 工作树在运行前后均 clean。本次命令在访问 Server 前即失败。
- 新 slot 按卡面明确属于 declaration-only，provider wiring 不在本卡；但 declaration 必须先补足 P0-1/P0-2，
  不能把公共形状交由 A-2 猜测。
