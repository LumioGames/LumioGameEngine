### 2. 必须实现的组件能力

#### A. ECS 归属与端别

- LogicTransform、ModelTransform 都按 Runtime 的真实 ECS 组件方式实现，沿用 `Component`、EntityType、生成注册与 `Get<T>()` 查询。
- Logic 承载逻辑位姿；Model 承载客户端显示位姿。Model 属于已有角色的客户端部分，不为角色创建新的 Local Entity 或表现 World。
- 服务器不创建 / 推进活跃的 Model 表现能力，也不因此依赖 GPU、Unity、浏览器或模型资源包。源码在 Runtime 与仅客户端运行是两件事。
- Model 与自己的平滑缓存随原 Entity 的组件生命周期管理；不建立模型保管表、加载系统或 Transform 专用生命周期管理器。

#### B. 基础数学与 API

- Float32，1 单位 = 1 米，Y 向上、XZ 水平；角色位姿允许小数米，不按体素格吸附。
- 提供世界 / 局部 Position、Quaternion Rotation、Pose / TRS、局部及世界矩阵、正逆坐标转换。
- 提供 Forward / Up / Right、明确单位的欧拉角便捷面、Translate、Rotate、RotateAround、LookAt，以及位置与旋转成组更新。
- 区分点、向量、方向：点包含平移 / 旋转 / 缩放；向量不含平移；方向仅旋转且保持长度。
- Logic 首期 Scale 固定为 1，非单位逻辑缩放请求拒绝；Model 支持表现 Scale。完整矩阵与近似世界缩放的边界写清，不保证任意剪切矩阵都能无损还原成 TRS。
- 没有父时 Local 与 World 一致；有父时世界位姿从局部真值派生。世界写入口反算局部值，不能保留两套独立可写位置。
- 复用现有数学库；仓内没有统一后端时优先标准库数值能力，明确四元数 / 矩阵组合顺序并用轴向测试固定。方法名适配现有风格，不另造重复数值类型体系。
- 无效数值、近零四元数、不可逆操作、无效 LookAt 输入明确失败。组合调用先校验再修改，不能只改位置却拒绝后面的旋转。

#### C. 写入检查

- 每次修改 Logic 位姿前，检查本实体当前控制者，越权拒绝并明确报错。普通 setter、成组更新、便捷操作和 Teleport 都不能绕过。
- 同一合法控制者同 Tick 可以连续更新，不实现“一帧只能写一次”的错误限制。
- 类型配置同时存在竞争写者而没有互斥关系时，在生成 / 启动阶段报错。运行时检查仍必须存在。
- 只实现组件所需的最小控制身份 / 受控入口接线，复用框架执行上下文；不能仅凭调用者自己填一个枚举获得权限。
- 不开发 MovementComponent、角色控制状态机、完整控制权仲裁系统或物理接管算法。测试可用两个测试控制者验证合法与越权路径。
- 初始化、结构结算和权威字段应用使用框架受限入口；保留已有线程 / 阶段 / Rejected / Fatal 规则，不新造 fail-stop 或恢复体系。

#### D. 父子关系

- 子组件记录父身份与局部位姿，Runtime 维护派生只读直接子索引；支持 Parent、Root、ChildCount、直接子枚举 / GetChild、IsChildOf、SetParent 和 Detach。
- 单父、禁止自挂和成环，修改接入已有 ECS 结构请求与结算。不能由一个组件析构时自行遍历、改写其他实体关系。
- 默认换父 / 解绑保世界位姿；明确的保局部 / 对齐语义沿设计实现，会瞬间改变世界位姿的操作必须保留显式跳变语义。
- 父更新后，同 Tick 后续业务读取子的世界位姿立即得到新值；派生计算不算第二个业务写者。
- 父实际销毁时，默认存活子解绑保世界位姿；子销毁只清父索引；双方销毁不发布临时复活的子。随父销毁只在显式选项启用时生效。
- 断线或客户端父副本离开 AOI 不自动等于服务器父实体销毁。复用既有原因与引用失效语义，不开发新的 AOI 系统。
- 查询只回答谁挂着谁。车载容量、座位分配、上下车 / 背负玩法不在范围内。

#### E. Teleport

- 提供显式世界 / 局部 Teleport 入口。改变逻辑位姿的同时保留可识别的跳变标记，普通移动不清掉最近标记。
- Model 首次消费新跳变时清旧平滑历史，直接定位到本次最新完整结果；TP 后又移动的合并结果不能丢掉跳变语义。
- 重复同一跳变标记不重复清历史，迟到旧样本不拉回位置。明确挂接的子继承父 TP 的不连续性。
- 只实现组件的标记保存 / 传递 / 消费合同。跨 GAS 预测与权威执行的操作身份映射由外部提供，不在本任务实现输入历史或预测去重引擎。
- Transform 不自管运动速度；不因为实现 TP 顺带创建速度组件、物理重置流程或传送玩法。

#### F. Model 的基础样本消费

- 提供组件可用的完整位姿值输入，带现有实体有效性、时间 / 顺序、参考和跳变所需元数据；不把 ECS 可变对象或旧预测句柄当样本保存。
- 实现基础位置插值、旋转最短弧插值、普通纠偏误差按经过时间衰减、无新样本时有界等待 / 有适用速度时有限表现外推；缓冲有上限。
- 显式 TP 直接到最新结果；首次有效样本直接定位，不能从原点插过去。Model 绝不反写 Logic。
- 明确挂接按父先子后组合。平台相对位姿可作为外部提供的参考样本消费与测试，但**不计算角色是否站在平台上，不实现支撑检测 / 跳跃 / 平台带动求解**。
- Model 只接收外部已经完成的逻辑结果。保留与既有提交边界接线的位置，组件本身不负责执行权威应用 + GAS 重放联合事务。
- 平滑是组件范围内的纯数值能力，不建立渲染引擎、网络时钟同步服务、通用表现管线或动画系统。C# 测试用受控时钟和有效样本驱动即可。

#### G. 同步、存档与生成接线

- Logic 的逻辑位姿 / 父引用等字段接入既有声明式同步与必要持久化；Model、矩阵缓存、派生子表和平滑历史不进入逻辑同步 / 存档 / Hash。
- 可以修改这两个组件直接需要的 Runtime 内生成模板、注册、字段编码 / 守卫和生命周期接线，修改量须能解释为本组件的直接依赖。
- 不手改生成物，不另写专用网络协议，不补齐整个生成器或全部 Sync 类型矩阵。
- Float / Quaternion / 引用字段若缺少必要的公共编码合同，先核实当前实现和已批准合同。需要改架构仓 wire / ABI 才能继续的部分记录具体缺口，完成其余独立能力，不擅自分配新协议 ID 或跨仓改合同。
- 不实现按观察者生成父不可见世界兜底包或平台相对同步优化；组件保留接收明确世界兜底 / 相对样本的能力。该消费路径可局部验证，网络投影交回为外部依赖。
