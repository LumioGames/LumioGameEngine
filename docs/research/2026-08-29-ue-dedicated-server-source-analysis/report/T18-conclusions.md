# T18 · 源码级结论与可迁移性再判定（收尾章）

> 只有观点，且每个观点挂前章坐标。UE 5.8.2（git ff8421f2b）。

## 18.1 可迁移设计原则（升级版，五段式）

**P1 · 把「diff 一次、分发多次」做成复制内核的第一公理。**
UE 体现：共享 changelog + 每连接游标（T4，EV-029/030/031）。没有它：每连接独立 diff，连接数直接乘进 CPU。隐含前提：对象状态可廉价快照（UE 靠浅拷贝容器指针语义）。前提不成立时：仍成立——ECS 提交点 + 帧哈希让 diff 退化为哈希比对，比 UE 更便宜；浏览器/WASM 环境无影响。**可移植性：高。**

**P2 · 发送预算用「token bucket + 截断回流」实现，永远不要「丢弃」。**
UE 体现：QueuedBits（T5.9，EV-049/050）+ bPendingNetUpdate 回流（EV-047）。没有它：饱和即状态丢失或带宽振荡。隐含前提：对象有「下一帧再来」的寄存点（UE 的 FNetworkObjectInfo）；无通道对象需另设重试。前提不成立时：仍成立——目标引擎的命令队列天然是回流点。**可移植性：高（突发上限应显式化，UE 的 2 帧是隐式常量）。**

**P3 · 可靠性属于消息层，不属于传输层；但可靠性必须有降级而非只有断连。**
UE 体现：bunch 层可靠（T2，EV-015/016/017）。没有它：包级重传无法表达跨包逻辑消息、无法按通道隔离反压。隐含前提：底层是不可靠数据报（UE 的原生假设）；消息粒度与通道粒度可对齐。前提不成立时（可靠有序流传输）：可靠性层变冗余但无害（WebSocket 驱动即证，EV-091）；不可靠数据报（WebTransport）下原样需要。**UE 的 512=断连是应剔除的部分（改反压+降级）。可移植性：结构高、参数低。**

**P4 · AOI 是带滞回与节流的连续判定，不是离散事件；事件是派生物。**
UE 体现：RelevantTimeout=5s 滞回 + ~1Hz 重查 + 通道开关即事实事件（T6，EV-046/056/058）。没有它：边界抖动直接变成实体创建/销毁风暴。隐含前提：有每连接的相关集缓存。前提不成立时：仍成立——体素世界用半径差滞回带等价替换。**可移植性：高；但「事件」应显式化（UE 的隐式通道事件 + startup actor 僵尸状态是反面教材，EV-046 的 5884 行）。**

**P5 · 版本兼容用「单一校验和 + 精确匹配」，多版本共存交给会话/网关层。**
UE 体现：GetLocalNetworkVersion CRC32 + IsNetworkCompatible 全等 + 能力位集（T3，EV-025/026）。没有它：线协议歧义。隐含前提：单服务器版本运营形态。前提不成立时（滚动更新诉求）：匹配逻辑本身仍可用，但需要在其上加「版本区间/定向降级」——UE 无参考实现，只有 Iris 位集这个先例。**可移植性：机制高、形态需扩展。**

**P6 · 无状态准入（cookie 化的连接验证）放在分配任何状态之前。**
UE 体现：HMAC cookie + 双 Secret 轮换 + 定长防放大（T3，EV-022/023）。没有它：伪造源洪泛吃内存。隐含前提：地址可作为弱身份。前提不成立时：浏览器下 WSS 已过 TLS+源检查，cookie 变冗余但无害；鉴权 token 仍是应用层必须。**可移植性：高（把「状态分配推迟到验证后」作为原则，具体密码学可替换）。**

**P7 · 预测的契约是「输入可重放 + 步长两端一致 + 状态差量可量化」，三缺一即不可预测。**
UE 体现：CMC 的 MoveAutonomous 双端同函数 + 服务器重算 dt + 定点量化（T10，EV-083/084/086）。没有它：任何一环断裂即纠正风暴。隐含前提：连续模拟、小状态差量。前提不成立时（体素离散事件）：更容易满足——离散输入天然可重放可哈希。**可移植性：高，且目标引擎的固定步长让「步长一致」从补丁变默认。**

**P8 · 时间同步至少要做 RTT/2 校正与离群剔除——UE 没做，不要学。**
UE 体现：GameStateBase 10Hz 均值 + 0.5 阻尼（T9，EV-082）。隐含前提：无。前提不成立时：不适用——这是纯粹的改进项。**可移植性：原则（校正+剔离群）直接采纳，UE 实现仅作反面参照。**

**P9 · 复制节拍与模拟节拍解耦：对象级频率门 + 自适应插值 + 随机抖动。**
UE 体现：NetUpdateFrequency/MinNetUpdateFrequency/OptimalNetUpdateDelta/RandDelay（T5，EV-044/054）。没有它：同帧齐发造成包尖峰；tick 率变化穿透到发送模式。隐含前提：模拟帧率高于发送需求。前提不成立时：固定步长下更应保留（发送降频是确定性模拟之上的调度问题）。**可移植性：高。**

**P10 · 录像=输入流+状态快照，不是「录线路流量」。**
UE 体现：DemoNetDriver 全部复杂度都源于只录复制流（T13，EV-098..103）。没有它：（UE 的做法）检查点脆弱、guid 假设、dormancy 交互、快进丢 RPC。隐含前提：UE 无确定性状态可快照。前提不成立时（目标引擎有 WAL+哈希）：整条路线应替换。**可移植性：原则可移植（结论是「别抄 UE 的实现」）；存储抽象接口（streamer）与跨帧摊销值得抄。**

**P11 · 把「连接」与「会话身份」分离，连接可过继、会话可恢复。**
UE 体现：seamless travel 的 SwapPlayerControllers 过继（T15，EV-113/114）证明分离可行，但也只在 travel 一条路径上做了。没有它：断线=身份消亡。隐含前提：无。前提不成立时：不适用——目标引擎明确要求此项。**可移植性：手法可移植，token/保鲜/回收必须自建（UE 无）。**

**P12 · 服务器对畸形输入的策略要显式分层：可容忍（跳过）/可恢复（钩子）/致命（断连），并允许两端策略不同。**
UE 体现：服务器必断/客户端容忍的分裂（EV-106）+ FaultRecovery 空钩子（EV-109）+ 日志限速踢人（EV-108）。没有它：要么过度断连要么过度容忍。隐含前提：无。**可移植性：原则高；UE 的具体分层（尤其「绕过 Close 的特例」EV-107）是清理对象。**

## 18.4 浏览器传输裁决（T11 收拢）

**原样继承**：复制内核（T4 全部机制思想）、调度（T5 预算/优先级/回流）、协议序列与准入（T3）、通道=流的映射关系（T11.3 表）。**必须重造**：包层交付抽象（按通道声明可靠/不可靠，映射 WebTransport 流/报文或 WebSocket+自建不可靠）、拥塞→复制降频映射（UE 缺失）、连接句柄式发送接口（LowLevelSend 地址路由倒置）、鉴权前限流。**直接砍掉**：PacketHandler 加密（TLS 覆盖）、无状态握手 cookie（保留原则可保留实现于不可靠数据报路径）。

## 18.5 UE 没解决、目标必须自己解决的清单

| 项 | UE 为什么没解决 | 出处 |
|---|---|---|
| 断线重连/恢复令牌 | 不在其对象模型内（连接=PC 生命周期） | T15 |

## 18.6 最该提前规避的五条坑（从 T14/T15/T17 证据提炼）

1. **「截断=丢弃」错觉**：任何发送预算机制必须配回流（UE 的 MarkRelevantActors 是被血泪逼出来的，EV-047）——目标引擎的 chunk 差量队列照抄此结构。
2. **每连接影子状态**：新写复制系统时最容易复刻的错误模型（预研自己也中招，CW-01）；设计文档里写死的应是「diff 共享、分发隔离」。
3. **可靠队列无降级**：慢客户端直接顶爆 512 断连（EV-015）；目标引擎的可靠通道必须有「降频+反压+最终断连」三级而非一级。
4. **客户端可拒收纠正的默认洞**（EV-088）：信任边界上每一条「客户端单方面开关」都应被服务器侧计数与升级处罚覆盖。
5. **日志/调试输出也是攻击面**（EV-108）：服务器侧任何按请求方放大输出量的路径都要限速——浏览器下的 WSS 升级错误页同理。

## 18.7 本次主动新增的发现（提示词未问但对委托方关键）

- **Restart Handshake 的连接恢复语义**（EV-024）：UE 包层存在「地址变化→重握手→恢复既有连接」的原语，被所有人忽略；目标引擎的 NAT 重绑定场景可直接借鉴。
- **Iris 的多 ReplicationSystem 内联 8 个**（EV-074）：引擎层面对多世界/多房间的唯一显式预留——若走「先经典后 Iris」演进路线，多世界诉求应早于此规划。
- **`EDataStreamWriteMode::DebugData` 免带宽调试流**（EV-073）：可观测性进协议的第一等设计，目标引擎的观测通道应同构。
