# 调研方法与证据分级

1. 先按目标画像拆出谱系、World/Entity/Component、生命周期、同步、AOI、执行、性能、预测、确定性、工具链十一个问题域。
2. 每个问题优先找官方文档；开源框架再找仓库、Release、Issue与带行号源码。没有源码时不把文档行为推成内部实现。
3. 对跨版本行为锁定文档版本或发布日期；无法锁定时标 `Reported` / `待核`。
4. 事故证据优先采用官方 changelog、源码注释与可复现 Issue；社区经验只用于补充。
5. 对性能数字不跨硬件/负载比较；报告只提结构性权衡，并给目标 benchmark Gate。
6. AOI论文只使用实际读到的摘要/元数据；付费正文未读部分不引用复杂度或实验数字。
7. 规范性建议集中在报告 P 章；A–O尽量保持事实与显式标注的推断。

## 可复核性

- 所有来源编号在 `../sources.md` 中给出类型、URL、访问状态和支撑章节。
- Mirror 的源码级论断带 ref 与行号；其余深挖主要为官方文档级。
- 本压缩包不包含第三方源码、网页快照或截图。
